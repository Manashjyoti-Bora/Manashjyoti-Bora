# mjb.os — install guide

Everything here goes into your **profile repository**: `github.com/Manashjyoti-Bora/Manashjyoti-Bora` (branch `main`).

## File tree to end up with

```
Manashjyoti-Bora/
├── README.md                        <- replaces your current one
├── assets/
│   ├── boot-dark.svg   boot-light.svg      (18s three-act banner)
│   ├── dock-portfolio.svg  dock-nexusmart.svg
│   ├── dock-devhire.svg    dock-taskflow.svg  dock-contact.svg
│   ├── footer-dark.svg  footer-light.svg
│   └── live-dark.svg    live-light.svg      (auto-regenerated by Actions)
├── build_hero.py  build_dock.py  build_footer.py     (sources of the SVGs)
└── .github/
    ├── scripts/live_stats.py
    └── workflows/live-stats.yml
```

Your existing `assets/*.svg` files (hero, fx-matrix, roadmap …) and the snake / pacman / profile-3d workflows are **not** referenced by the new README. Leave them or delete them — nothing breaks either way.

## Install from a phone (GitHub web UI only)

1. Open your profile repo → **Add file → Upload files**.
2. Drag the `assets` folder (or select all 11 SVGs and type `assets/` in front of the filename field). Commit.
3. Repeat for `build_hero.py`, `build_dock.py`, `build_footer.py` at the repo root.
4. Create `.github/scripts/live_stats.py` — use **Add file → Create new file** and type the full path, then paste the contents.
5. Create `.github/workflows/live-stats.yml` the same way.
6. Finally, open `README.md`, select all, paste the new one, commit.
7. Go to **Actions → Live telemetry → Run workflow**. It regenerates `assets/live-*.svg` from your real GitHub data and commits them back.

## Install from a terminal

```bash
git clone https://github.com/Manashjyoti-Bora/Manashjyoti-Bora
cd Manashjyoti-Bora
# copy the unzipped mjbos/ contents over the repo, then:
git add -A && git commit -m "feat: mjb.os profile" && git push
```

## Editing later

The SVGs are generated, so edit the generator and re-run it — do not hand-patch the SVG:

```bash
python3 build_hero.py     # boot banner, both themes
python3 build_dock.py     # the five clickable tiles
python3 build_footer.py   # terminal footer, both themes
```

- Boot log lines live in the `LOG` list in `build_hero.py`.
- Act 3 stat cards live in `BARS` and `facts`.
- Tile titles, subtitles and accent colours live in `TILES` in `build_dock.py`.
- Footer shell lines live in `LINES` in `build_footer.py`.
- The whole banner shares one 18-second timeline (`T = 18.0`), which is why the three acts cross-fade in sync. If you change `T`, every keyTime rescales automatically.

## Live telemetry notes

- Runs on cron `17 */6 * * *` (every 6 hours), on manual dispatch, and on push to `main`.
- Uses the built-in `secrets.GITHUB_TOKEN` — no personal access token, no third-party service.
- If the API is slow or rate-limited it degrades to empty values and still exits 0, so the workflow never turns red.
- For an offline preview: `MJB_MOCK=1 python3 .github/scripts/live_stats.py`

## Two things worth knowing

- Animated SVG **cannot** carry hover effects or scripts on GitHub — only SMIL animation runs. Everything here is SMIL, so it plays in the README, in dark and light mode, on mobile.
- To make an animated SVG clickable, it has to be an `<img>` inside an `<a>` (that is what the dock table does). An inline `<svg>` in Markdown would be stripped.
