# 📖 01 · The Story — Why a Phone?

</div>

I don't own a laptop. My entire development environment is an Android phone:
**Termux** for Git and Node.js, **GitHub's web editor** for code, and **Vercel**
for cloud builds. The constraint was never a wall — it became the brand.[^2]

```diff
- Excuse:  "I'll start when I get a laptop."
+ Reality: 2 production apps shipped from a phone.
```
